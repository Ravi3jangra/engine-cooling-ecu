# 🚗 FSM Engine Cooling Controller

An automotive engine cooling controller designed using MATLAB/Simulink and Stateflow to regulate engine temperature using finite state machine (FSM) logic.

The system dynamically controls cooling fan operation based on temperature thresholds to maintain optimal thermal conditions.

---

## 🚀 Features

- Finite State Machine (FSM) based control
- Dynamic fan speed regulation
- Multi-state cooling logic
- Real-time temperature response
- Stable thermal management
- Automotive ECU-oriented design

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| MATLAB | Modeling & Analysis |
| Simulink | Dynamic Simulation |
| Stateflow | FSM Logic Design |

---

## ⚙️ System Working

1. Engine temperature is continuously monitored.
2. Temperature thresholds determine FSM state transitions.
3. Fan speed changes dynamically according to thermal conditions.
4. System maintains safe engine operating temperature.

---

## 🔄 FSM States

| State | Fan Operation |
|---|---|
| OFF | No cooling required |
| MEDIUM | Moderate cooling |
| FULL | Maximum cooling |
